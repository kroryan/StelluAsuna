deepslate.register_conversion (from, to, param2)
Registers a node to be converted during deepslate generation.

Parameters:

  • from The name of the node to replace.
  • to The name of the node to replace it with.
  • param2 The param2 value for the new node, or `deepslate.PRESERVE_PARAM2` to keep the old node's param2.

Returns:

    true if the conversion was registered, or false if either node was unavailable.
deepslate.register_ore (name, ore_name, options, override)
Registers a deepslate version of an ore node.

Parameters:

  • name The namespaced ID of the deepslate ore node to register.
  • ore_name The namespaced IF of the original ore node.
  • options A table of additional options: ore_texture.
  • override A partial node definition table, which overrides the generated definition.

Returns:

    true if the ore node was defined, or false if the original ore is not available.

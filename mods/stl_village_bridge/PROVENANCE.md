# stl_village_bridge provenance status

This integration is present in the first StelluAsuna commit `674a699` and was
restored by commit `e7c2007` after a temporary removal. It connects
`mg_villages` bed data to `working_villages` resident entities and is not an
upstream Stellua component. The official Asuna 1.1.5 and Stellua 0.4.4
ContentDB releases were checked and contain no `stl_village_bridge` or
`stl_asuna_bridge` directory. The root commit records when these files first
appear in this repository, not their pre-repository source.

No exact ContentDB package named `stl_village_bridge` was found. The project
owner has confirmed that this is project-owned bridge code, released under
GPL-3.0-or-later.

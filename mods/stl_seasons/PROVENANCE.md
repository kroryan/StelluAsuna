# stl_seasons provenance status

This mod was added to StelluAsuna in commit `e1fb3a0` as the project's own
seasonal integration. It exposes the `stellua.get_season()` API and handles
seasonal outdoor water freezing and melting.

The public ContentDB package `tbook/seasons` is a different mod with a
different file and API layout; it is not the source of this directory. This
directory also does not belong to the upstream Stellua revision preserved in
`LICENSE_STELLUA.txt`.

Ownership and redistribution license for this StelluAsuna-specific code must
still be confirmed.
